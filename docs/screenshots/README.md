# 演示素材清单（录屏规格）

主 `README.md` 的「🎬 演示」区引用以下 GIF，文件放本目录并**保持文件名一致**即可生效：

| 文件名 | 内容 | 建议 | 时长 |
|--------|------|------|------|
| `output.gif` | 开始录制：打开目标页面 → 点击扩展开始录制 → 页面操作 | 16:9，去鼠标噪音 | 10~15s |
| `output1.gif` | 标注：悬浮工具栏 + 矩形/箭头/文本标注 | 16:9 | 8~10s |
| `output2.gif` | 回放：时间轴播放 + 侧边栏控制台/网络面板 | 16:9 | 10~15s |
| `output4.gif` | 上传：选择产品/项目 → 提交禅道 → 拿到 Bug 链接 | 16:9 | 8~10s |

> 演示区用 GIF（比静态图更抓眼球）；如需静态图，可另行补充 PNG。

## 录屏工具建议（Windows）

- **GIF**：ScreenToGif（免费、轻量、可直接输出 GIF）
- **视频/高清**：OBS Studio（录 mp4，再用 ffmpeg/在线工具转 GIF）

## 录屏要点

1. 用**真实业务场景**（如"登录按钮点击无响应"），比示例数据更可信
2. 录制时**操作清晰、节奏适中**（不要太快）
3. 回放 GIF 里体现「时间轴 + 控制台报错 + 网络请求」三联动，最能体现价值
4. 录完放到本目录后，`README.md` 的「🎬 演示」区会自动生效
